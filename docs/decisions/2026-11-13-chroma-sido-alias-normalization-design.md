# Chroma 시·도 별칭 통합 설계

## 의도

검색과 화면에서 전북·전남의 구 표기와 새 표기를 같은 지역으로 취급한다. 사용자가 선택한 범위는 코드 수준의 별칭 처리이며, 현재 저장된 Chroma 메타데이터·CSV·평가 결과는 변경하지 않는다.

## 목표

- Chroma 지역 필터가 `전라북도`와 `전북특별자치도`를 같은 지역으로 검색한다.
- `전라남도`, 기존 Chroma 표기 `전남광주통합특별시`, `전남광주특별자치도`를 한 검색 지역으로 취급한다.
- Supervisor와 UI에 반환·표시되는 지역명은 `전북특별자치도`, `전남광주특별자치도`로 표준화한다.
- Hybrid의 BM25 필터도 Vector 필터와 같은 별칭 그룹을 적용한다.

## 제외 범위와 영향

- Chroma의 문서·임베딩·ID·메타데이터, 입력 CSV, 과거 평가 산출물을 직접 수정하거나 재생성하지 않는다.
- 지역 필터를 지정하지 않은 검색의 순위 산정은 변경하지 않는다.
- 이후 전북·전남 지역을 필터링한 Vector/Hybrid 검색은 이전보다 더 많은 동등 표기 레코드를 포함할 수 있다. 이는 요청한 통합 동작이다.

## 구현 접근

`src/region_aliases.py`를 별칭 정의의 단일 기준으로 두고, Supervisor 정규화·Chroma `where` 생성기·BM25 메타데이터 비교·UI 표시값에서 공유한다. 저장된 인덱스를 쓰지 않는 코드 경로만 변경한다.
