# 합친 경로: 그래프가 후보를 정하고 문서 검색이 설명을 찾는다

2026-11-15. 요구사항의 "벡터·그래프 하이브리드 검색"을 채우기 위해 추가한 `combined` 경로의 기록입니다. 구조 그림은 [합친 경로 설계도](../architecture/images/combined-route-design.png)입니다.

## 문제

- 지금까지 Supervisor는 한 번에 **한 경로**만 골랐습니다. `hybrid`는 Vector + BM25만 합치고 Neo4j를 쓰지 않았습니다.
- 그래서 "같은 기관이 운영하는 시설 중 전시를 볼 수 있는 곳"처럼 **관계와 설명이 함께 필요한** 질문은 어느 한쪽 경로로는 근거가 모자랐고, 재시도도 경로를 바꿔 근거를 버렸습니다.
- 참고 구조(Vector Agent와 Graph Agent가 근거 통합으로 모임)와 요구사항의 "두 결과를 결합한 검색"에 해당하는 경로가 없었습니다.

## 이름

| 경로 이름 | 부르는 이름 | 내용 |
|---|---|---|
| `hybrid` | 문서 검색 (Vector + BM25) | 지금까지의 Hybrid. 바꾸지 않음 |
| `combined` | 하이브리드 (문서 검색 + 그래프) | 이번에 추가 |

코드의 `hybrid`는 평가 결과·테스트·문서가 모두 묶여 있어 이름을 바꾸지 않았습니다.

## 선택한 구조

1. **그래프 먼저.** 준비된 쿼리 또는 Text-to-Cypher로 관계를 조회합니다. 기준 시설(anchor)은 후보에서 뺍니다.
2. **문서 검색은 그래프가 찾은 시설 안에서만.** `restrict_to_museum_ids`로 Vector·BM25·이름 보장을 제한하고, 온톨로지 필터 후보와는 교집합을 씁니다. 그래프가 시설을 못 찾았거나 실패하면 제한 없이 문서 검색을 합니다.
3. **점수를 섞지 않고 이어 붙입니다.** 문서 근거(재정렬 순위 있음)를 앞에, 그래프 근거(점수 없음)를 뒤에 두고 `evidence_id`를 다시 매깁니다. 같은 시설의 같은 본문은 중복을 제거합니다. 각 근거에 `retrieval_branch`(document/graph)가 붙습니다.
4. **한쪽이 실패해도 다른 쪽 근거는 유지합니다.** 둘 다 실패하면 실패 사유를 남깁니다.
5. **검증에 실패하면 재시도 없이 보류합니다.** 이미 두 검색을 모두 썼고, 문서 검색만 다시 하면 그래프 관계를 버리고 무관한 본문으로 바뀌었습니다(아래 실험).

## 대안과 버린 이유

| 대안 | 버린 이유 |
|---|---|
| 그래프와 문서 검색을 동시에 실행 | 처음 구현했으나 문서 검색이 조건 없이 전체에서 찾아, 같은 기관이 아닌 시설이 근거로 올라왔습니다 |
| 두 결과를 점수로 합쳐 한 순위로 | Cypher 결과에는 관련도 점수가 없고 Cross-Encoder 점수와 비교할 수 없습니다 |
| 합친 뒤 Cross-Encoder로 한 번에 재정렬 | 그래프 근거는 짧은 관계 문장이라 점수가 낮게 나올 위험이 있습니다. 개선안으로만 둡니다 |

## 실제 질문으로 확인한 것 (2026-11-15, 실제 Neo4j·Chroma·LLM)

| 질문 | 구조 | 결과 |
|---|---|---|
| 창녕박물관과 같은 기관이 운영하는 시설 중 유물을 볼 수 있는 곳은? | 동시 실행 | 보류. 문서 근거 5건이 모두 다른 지역 박물관이라 운영 기관 관계와 이어지지 않았음 |
| 같은 질문 | 그래프 먼저 + 제한 | 문서 근거가 박진전쟁기념관 1건으로 좁혀졌으나 설명에 유물 언급이 없어 보류. 이후 재시도가 문서 검색만 다시 해 관계를 버렸고 → 재시도 없이 보류로 수정 |
| 창녕박물관과 같은 기관이 운영하는 시설 중 전쟁 관련 전시를 볼 수 있는 곳은? | 그래프 먼저 + 제한 | 답변. 박진전쟁기념관을 제시하고 운영 기관 관계(E2·E3, 그래프)와 전시(E1, 문서)를 함께 인용. 재시도 0회 |

첫 번째 보류는 틀린 답이 아닙니다. 데이터상 창녕박물관과 같은 운영 기관인 다른 시설은 박진전쟁기념관 1곳이고 그 설명에 유물이 없으므로 "근거 없음"이 맞습니다.

## 라우팅

- 준비된 그래프 쿼리에 맞고 설명 단서(전시·유물·소장·체험·프로그램·역사·문화재·시대·볼 수 …)가 함께 있으면 `combined`, 없으면 `graph`.
- LLM 라우터는 Graph가 연결된 경우에만 `combined`를 고를 수 있습니다. Graph가 없으면 `hybrid`로 대체됩니다.
- `--route combined`로 명시할 수 있습니다. Neo4j 연결(`--with-neo4j`)이 필요합니다.

## 한계

- 평가셋 v2에는 이 경로를 겨냥한 문항이 없습니다. 위 실험은 질문 3개이며 점수로 환산하지 않았습니다.
- 설명 단서는 규칙(정규식)이라 놓치는 표현이 있습니다. 그런 질문은 `graph`로 갑니다.
- 그래프 먼저 실행하므로 Text-to-Cypher 경로에서는 지연이 더해집니다. 준비된 쿼리는 짧습니다.
- Streamlit 화면은 이 흐름을 쓰지 않습니다.
