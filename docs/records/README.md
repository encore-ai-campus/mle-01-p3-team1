## 검증 수준과 기록에 남길 정보

기록의 주장은 어느 수준까지 확인했는지 함께 적습니다. 아래는 서로 다른 수준입니다.

| 수준 | 확인한 것 | 말할 수 있는 것 | 말할 수 없는 것 |
|---|---|---|---|
| 1. 단위 테스트 통과 | 외부 서비스를 대체한 코드 동작 | 코드가 의도한 대로 분기·계산함 | 실제 서비스에서의 효과 |
| 2. 실제 DB·API 단건 조회 | 연결과 쿼리 결과 | 쿼리가 실제 데이터에서 동작함 | 챗봇 답변 품질 |
| 3. 챗봇 질문 단건 실행 | 한 질문의 전체 흐름 | 그 질문이 답변·보류됨 | 일반적인 정확도 |
| 4. 평가셋 점수 | 평가셋 전체의 지표 | 평가셋 기준의 수치 | 사람 검수 전 라벨이면 잠정치 |
| 5. 사람 검수 라벨 기준 점수 | (아직 없음) | | |

평가 결과를 보존할 때는 다음을 함께 남깁니다. 예시는 [첫 v2 평가](../../evaluations/reports/run_2026-11-14_supervisor_full_v2_first/README.md)입니다.
- 코드 상태(브랜치·커밋, 커밋되지 않은 변경 여부)와 이번 실행에 반영된 수정
- 평가셋 버전, 문항 수, 파일 해시, 라벨 검수 상태
- 모델, 검색 모드, top-k, 병렬도, 검색 설정(후보 수·RRF·재정렬), 후보 필터·이름 보장 등 켜진 기능
- 데이터·DB 식별 정보(CSV 해시, 그래프 노드·관계 수)
- 질문별 결과, 실패 사례, 평균·최대 시간
- 변경 전후 비교가 같은 조건인지 여부 (문항·경로가 다르면 전체 평균을 비교하지 않음)
